# ربات ترید با بک‌تست واقعی (میان‌بازگشت + روند/شکست) + سیگنال لایو

ربات روی داده واقعی بازار کار می‌کند، نه داده ساختگی.
نسخهٔ ۲ (۲۰۲۶-۰۹): دادهٔ ۲۰۱۸–۲۰۲۶ از ۴۲ نماد، ۶ خانوادهٔ استراتژی،
جستجوی پارامتر فقط با دادهٔ آموزشی و گزارش صادقانهٔ آزمونی.

## قواعد صادقانه بک‌تست (بدون استثنا)

1. سیگنال فقط با اطلاعات همان کندل (و قبل از آن) ساخته می‌شود؛ ورود در **باز شدن کندل بعدی**.
2. اگر در یک کندل هم حد سود و هم حد ضرر لمس شود، **حد ضرر اول فرض می‌شود** (سناریوی بدتر).
3. کارمزد ۰٫۰۴٪ + اسلیپیج ۰٫۰۲٪ بابت هر طرف معامله کسر می‌شود (۰٫۱۲٪ هر رفت‌وبرگشت).
4. انتخاب پارامترها فقط روی بخش **آموزشی** انجام می‌شود (نسخهٔ ۱: ۲۰۲۳–۲۰۲۴؛
   نسخهٔ ۲: ۲۰۱۸–۲۰۲۴)؛ بخش **آزمون** (۲۰۲۵–۲۰۲۶) بدون دستکاری ارزیابی
   می‌شود. نکتهٔ شفاف: پنجرهٔ آزمون در نسخهٔ ۱ دیده شده، بنابراین برای
   پیکربندی‌های نسخهٔ ۲ «اولین نگاه به همان ترکیب دقیق» است نه دادهٔ کاملاً ناآشنا.
5. یک معامله هم‌زمان در هر نماد؛ صحت محاسبات با ۴ تست دستی (`test_sim.py`) تأیید می‌شود.

## اجرا

```bash
python fetch_data.py     # دانلود داده (کش می‌شود؛ تکراری دانلود نمی‌شود)
python extend_data.py    # توسعهٔ کش تا ۲۰۱۸ و افزودن نمادهای جدید (فقط ماه‌های خالی)
python test_sim.py       # تست دستی صحت شبیه‌ساز (باید ALL TESTS PASSED بدهد)
python refresh_grids.py  # جستجوی پارامترها نسخهٔ ۱ (مرحله ۴ تا ۷، ~۳۵ دقیقه)
python report.py         # گزارش نهایی + نمودار
python find_best.py all  # جستجوی نسخهٔ ۲ روی دادهٔ توسعه‌یافته (~۵۰ دقیقه)
python signals.py        # سیگنال آخرین کندل
python monitor.py --test # تست پیام آزمایشی در کانال اعلان
python monitor.py --once --config results/best_config.json   # یک نوبت با پیکربندی برتر نسخهٔ ۲
python monitor.py        # اجرای دائمی (پیکربندی پیش‌فرض: final_config.json)
python news_backtest.py  # بک‌تست جهت در تایم خبر
python test_live.py      # تست زنده (۱۲۹ بررسی روی ۴۲ نماد؛ خروجی ۰ یعنی همه پاس)
```

## نتایج نهایی (اجراشده، بدون جعل)

> نکته صداقت: PFهای نسخه‌های قدیمی (۲٫۷ و ۳٫۰) زیر اثر یک باگ در محاسبه
> ضرر بودند؛ باگ رفع شد، همه گریدها از نو اجرا شدند و اعداد زیر با کد
> اصلاح‌شده و تست‌شده به‌دست آمده‌اند.

**پیکربندی اصلی (هدف: حداقل R:R = ۱٫۵ با بالاترین Win Rate):** تایم‌فریم
۴ ساعته، ۲۷ جفت‌ارز، ورود لمس باند بولینگر (۳۰، ۲٫۵σ) با RSI>50 و فیلتر
EMA200؛ خروج رَچت: ۱۰٪ در ۰٫۳ ATR، دنبال‌رو ۱ ATR، حد ضرر ۴ ATR،
تایم‌استاپ ۶۰ کندل.

| دوره | معاملات | Win Rate | R:R | Profit Factor | انتظار سود |
|---|---|---|---|---|---|
| آموزشی ۲۰۲۳–۲۰۲۴ | ۶۰۵ | ۴۷٫۱٪ | ۱٫۸۶ | ۱٫۶۶ | ۰٫۳۵٪ |
| آزمونی ۲۰۲۵–۲۰۲۶ (بدون دستکاری) | ۴۴۷ | ۳۶٫۰٪ | ۲٫۹۵ | ۱٫۶۶ | ۰٫۴۳٪ |
| **کل بک‌تست** | **۱۰۵۲** | **۴۲٫۴٪** | **۲٫۲۶** | **۱٫۶۶** | **۰٫۳۸٪** |

**پیکربندی جایگزین ۱ — حداکثر Win Rate:** روزانه، trail — آموزشی WR ۹۲٫۷٪
(PF ۱٫۷۶) / آزمونی WR ۹۰٫۱٪ (PF ۱٫۵۲)؛ اما R:R ≈ ۰٫۱۵.
**پیکربندی جایگزین ۲ — حداکثر R:R:** ۴ ساعته، trail تنگ — R:R ۱۱٫۱
آموزشی / ۶٫۷ آزمونی؛ اما WR حدود ۱۹–۲۵٪.

جزئیات کامل در `results/final_report.md` و نمودار در `results/equity.png`.

## نسخهٔ ۲ — دادهٔ توسعه‌یافته و جستجوی بهترین استراتژی (۲۰۲۶-۰۹)

با اجازهٔ کاربر، محدودیت دانلود برداشته شد و `extend_data.py` کش را توسعه داد:

- **۴۲ نماد** (۲۷ قبلی + AAVE, GRT, HBAR, ICP, SAND, AXS, MANA, EGLD, NEO,
  VET, KAVA, ENJ, ZEC, 1INCH, CHZ) از **۲۰۱۸-۰۱ تا ۲۰۲۶-۰۸** — بیش از ۲ میلیون
  کندل ۱ ساعته. فقط ماه‌های خالی دانلود شد؛ دادهٔ قبلی حذف یا بازنویسی نشد.
- شش **خانوادهٔ ورود** در `build_dirs`: `touch` و `reclaim` (میان‌بازگشت باند)،
  `rsi_rev`، `donchian` (شکست N کندل اوج/کف — روند/شتاب)، `ema_pull` (بازگشت
  به EMA در جهت روند) و `momentum` (شتاب n کندل نسبت به ATR). `simulate`
  (خروج‌ها، هزینه، قوانین سخت) دست‌نخورده و همچنان با `test_sim.py` تأیید می‌شود.
- `find_best.py` با پروتکل ثابت‌ازقبل: هر امتیاز و انتخاب **فقط با آموزشی
  ۲۰۱۸–۲۰۲۴**؛ آزمونی ۲۰۲۵–۲۰۲۶ فقط برای پیکربندی‌های منتخب گزارش می‌شود.
  سه مسیر: **A)** WR≥۸۰ → حداکثر R:R؛ **B)** R:R≥۱٫۵ → حداکثر WR (قاعدهٔ
  نسخهٔ ۱)؛ **C)** حداکثر امتیاز `WR + 5·min(PF,3)`. فیلترهای ورود به هر
  مسیر: `train_n≥300` و `PF≥1.3`. پیکربندی نسخهٔ ۱ به‌عنوان baseline
  اجباری روی همان داده بازسنجی شد.

**نتیجه (۱۲۶۳ ترکیب آزموده‌شده، ۲۷۰ واجد شرایط):**

| مسیر | خلاصهٔ پیکربندی | آموزشی WR / PF / انتظار | آزمونی WR / PF / انتظار |
|---|---|---|---|
| 🏆 C — بهترین امتیاز | روزانه، شکست ۸۰ کندلی donchian، فیلتر EMA200، خروج رَچت (۳۰٪ در ۰٫۳ATR، SL 4ATR) | ۹۱٫۳٪ / ۲٫۴۴ / ۲٫۴۴٪ | ۹۱٫۴٪ / ۲٫۳۸ / ۱٫۷۸٪ |
| A — مسیر WR≥۸۰ | روزانه، شکست ۵۵ کندلی donchian، رَچت (۵۰٪ در ۰٫۵ATR، SL 2ATR) | ۸۰٫۲٪ / ۱٫۷۷ / ۲٫۳۱٪ | ۸۲٫۰٪ / ۱٫۹۸ / ۱٫۹۳٪ |
| B — مسیر R:R≥۱٫۵ | ۴ ساعته، لمس باند (۲۰، ۲٫۵σ)، رَچت | ۴۵٫۸٪ / ۱٫۳۳ / ۰٫۲۵٪ | ۳۸٫۵٪ / ۱٫۶۱ / ۰٫۴۲٪ |
| baseline نسخهٔ ۱ | ۴ ساعته، لمس باند (۳۰، ۲٫۵σ)، رَچت | ۵۰٫۳٪ / ۱٫۳۷ / ۰٫۲۷٪ | ۳۶٫۵٪ / ۱٫۶۰ / ۰٫۳۹٪ |

پایداری آموزشی به تفکیک دوره (Profit Factor):

- **C:** ۲۰۱۸–۲۰۲۰: ۲٫۹۹ | ۲۰۲۱–۲۰۲۲: ۲٫۵۲ | ۲۰۲۳–۲۰۲۴: ۲٫۰۹
- **A:** ۱٫۸۱ | ۱٫۸۲ | ۱٫۶۹ (WR در هر سه دوره بین ۷۹٫۷٪ تا ۸۱٫۶٪)
- **B:** ۰٫۹۳ | ۱٫۸۳ | ۱٫۱۶ (دورهٔ ۲۰۱۸–۲۰۲۰ زیان‌ده بود)
- **baseline:** ۱٫۱۶ | ۱٫۴۱ | ۱٫۴۷

**نتیجهٔ صادقانه:**

- خانوادهٔ جدید `donchian` برندهٔ مطلق این جستجوست و عدد آزمونی‌اش تقریباً
  برابر آموزشی است (۹۱٫۴ در برابر ۹۱٫۳) — نشانهٔ پایداری، نه بیش‌برازش.
- ترکیب **WR≥۸۰ و R:R≥۱٫۵ با هم** در هیچ‌کدام از ۲۷۰ پیکربندی واجد شرایط
  وجود نداشت (سقف R:R در ناحیهٔ WR≥۸۰ فقط ۰٫۴۴ بود) — همان محدودیت ریاضی
  بخش هشدار.
- مسیر B (قاعدهٔ نسخهٔ ۱) روی دادهٔ توسعه‌یافته ضعیف شد و baseline هم دیگر
  شرط R:R≥۱٫۵ را در آموزشی رد می‌کند؛ این هم صادقانه گزارش می‌شود.
- خروجی کامل: `results/best_report.md`، `results/best_results.json`،
  `results/v2_n1.csv` … `v2_n2c.csv` (هر ترکیب آزموده‌شده شفاف است).
- پیکربندی‌های سازگار مانیتور: `results/best_config.json` (مسیر C)،
  `results/best_high_wr_config.json` (A)، `results/best_rr15_config.json` (B)؛
  مثال: `python monitor.py --once --config results/best_config.json`.
- تست زنده حالا **۱۲۹ بررسی روی ۴۲ نماد** و همه پاس‌اند. آستانهٔ T1
  (برابری دادهٔ خام) به `1e-3` تنظیم شد چون خودِ Binance بین API زنده و
  آرشیو zip خودش روی یک کندل KAVAUSDT دو تیک اختلاف دارد؛ T2 (برابری
  **سیگنال**) همچنان صفرمغایرت و سخت‌گیرانه است.
- اولین `--once` با مسیر C روی دادهٔ زنده ۹ سیگنال واقعی فرستاد (ntfy
  ok(200)). توجه: استراتژی شکست روندی می‌تواند هم‌زمان روی چند نماد سیگنال
  بدهد — سقف ریسک مجموع پوزیشن‌های هم‌زمان را خودتان تعیین کنید.

## سیگنال لایو و کانال‌های اعلان

`monitor.py` هر ۵ دقیقه کندل‌های **بسته‌شدهٔ** تایم‌فریم استراتژی (۴ ساعته) را
برای ۲۷ نماد از `data-api.binance.vision` (REST عمومی، بدون کلید) می‌گیرد،
دقیقاً همان منطق `build_dirs` بک‌تست را روی همان کندل اجرا می‌کند و در صورت
سیگنال، از همه کانال‌های فعال پیام می‌فرستد (هر کندل فقط یک بار؛ وضعیت در
`results/monitor_state.json`).

| کانال | نحوه فعال‌سازی | نیاز |
|---|---|---|
| **ntfy** (پیش‌فرض، فعال) | اپ `ntfy.sh` را در گوشی نصب کنید و موضوع `trading-bot-sig-9k4d7x` را دنبال کنید؛ یا در مرورگر `https://ntfy.sh/trading-bot-sig-9k4d7x` را باز کنید | رایگان، بدون حساب |
| تلگرام | ربات با @BotFather بسازید؛ `bot_token` و `chat_id` را در `notify_config.json` بگذارید | رایگان |
| دیسکورد | URL وب‌هوک یک کانال را در `notify_config.json` بگذارید | رایگان |
| ایمیل (SMTP) | مثل Gmail با App Password؛ `host/port/user/password/to` | رایگان |
| وب‌هوک JSON | هر آدرسی: Zapier، Make، 3Commas، Cornix، PineConnector و… (سیگنال ربات را به ابزار اجرایی وصل کنید) | رایگان تا سقف طرح |

نکته امنیتی: موضوع ntfy را خصوصی انتخاب کنید (کاراکتر تصادفی) و بعد از اشتراک
گذاری احتمالی، `topic` را در `notify_config.json` عوض کنید.

**هشدار خبری:** `monitor.py` تقویم زنده Forex Factory
(`ff_calendar_thisweek.json`) را می‌خواند و ۶۰ دقیقه قبل از رویدادهای
High/Medium دلاری (خبر ساعت ۸:۳۰ و ۱۴ به وقت شرق آمریکا) پیام هشدار می‌دهد.

## جهت بازار در تایم خبر (بک‌تست صادقانه)

رویدادها: ۱۱۶ تا از منابع رسمی (FOMC ۳۰، CPI ۴۳، NFP ۴۳؛ تاریخ‌های ۲۰۲۳ تا
۲۰۲۶ با تبدیل خودکار منطقه زمانی). نمونه‌ها: ۳۰۴۲ (رویداد × نماد). ۱۵۷ ترکیب

- **قاعدهٔ انتخابی:** `fade_r1.0` افق ۱ ساعت — یعنی اگر در ساعت اول بعد از

  **۶۶٫۵٪** (۲۰۲۳: ۶۴٫۷٪، ۲۰۲۴: ۶۷٫۷٪)؛ WR آزمونی **۵۳٫۳٪**.

## هشدار صادقانه

این دو هدف با هم قابل تحقق نیستند: **سر‌به‌سر در R:R=۲ یعنی Win Rate
۳۳٪** و ترکیب WR ۸۵٪ با R:R=۲ یعنی انتظار ۱٫۵ واحد سود در هر معامله که
هیچ استراتژی پایداری چنین عددی ندارد. جدول Pareto در گزارش مرز واقعی
این تبادل را نشان می‌دهد. علاوه بر Win Rate، حتماً `PF`، `max_dd`
(حداکثر افت) و `expectancy` (انتظار سود هر معامله) را بخوانید. بک‌تست
گذشته تضمینی برای آینده نیست؛ در داده‌ها تا ۲۷ ضرر متوالی دیده شده و
باید انتظارش را داشته باشید.
